### 👋 About Me

I'm a **Client-Side Developer** focused on creating, modifying and improving multiplayer gaming experiences based on GTA San Andreas and CRMP.

My work is focused on client architecture, game modifications, custom systems and performance optimization.

I enjoy working close to the game engine, exploring its internal mechanics and developing solutions that improve both functionality and user experience.

### 🛠️ What I Do

- **Client-Side Development** — custom functionality and game client modifications.
- **Plugin Development** — ASI / DLL plugins and game integrations.
- **Game Systems** — development of custom mechanics and gameplay features.
- **Performance Optimization** — improving stability, performance and resource usage.
- **Reverse Engineering** — investigating GTA SA internals and existing game systems.
- **UI / UX Development** — improving interfaces and player interaction.
